# ディフェンシブ銘柄 リスク回避度ランキング TOP50

- 期間: 2019-01-04 〜 2026-10-19（週次・月次リターン、配当は株価調整済みの値に含まず）
- ベンチマーク: TOPIX（TOPIX連動ETF `1306` で代用）
- 対象: ディフェンシブ業種の候補 90 銘柄のうち、3年以上のデータがある 89 銘柄を採点

## リスク回避度スコアの算出方法（0〜100、高いほど守りが固い）

候補内での順位（パーセンタイル）を重み付き平均したものです。

| 指標 | 意味 | 重み |
|---|---|---|
| β（ベータ） | TOPIX が 1% 動いたときに何%動くか（週次）。低いほど良い | 25% |
| 下方キャプチャ | TOPIX が下げた月に、その下げの何割を被ったか。マイナスは「市場が下げた月に上がった」 | 25% |
| 急落時の超過リターン | 下記4回のショック安での対TOPIX超過リターン平均 | 20% |
| ボラティリティ | 年率換算の値動きの大きさ | 15% |
| 最大ドローダウン | 期間中の高値からの最大下落率 | 15% |

急落局面: コロナ・ショック（2020-02-20〜2020-03-16）、2022年 利上げ急落（2022-01-04〜2022-03-08）、2024年8月 令和のブラックマンデー（2024-07-11〜2024-08-05）、2025年4月 トランプ関税ショック（2025-03-26〜2025-04-07）

## 相場局面の判定方法

| 局面 | 判定に使う値 | ◎ | ○ | △ | × |
|---|---|---|---|---|---|
| 下落相場 | TOPIX が下げた月の対TOPIX超過リターン | 候補内で上位16% | 候補内平均以上 | プラスだが平均未満 | マイナス |
| 急落局面 | 急落4回の対TOPIX超過リターン平均 | 同上 | 同上 | 同上 | 同上 |
| 円高 | 市場要因を除いたドル円への感応度（ドル円下落=円高でプラスなら強い） | t値≥2 | t値≥1 | 有意でないプラス | マイナス |
| 金利上昇 | 市場要因を除いた「銀行株の対TOPIX超過」への感応度（国内金利上昇の代理） | 同上 | 同上 | 同上 | 同上 |
| 資源高・インフレ | 市場要因を除いた ブレント原油への感応度 | 同上 | 同上 | 同上 | 同上 |

円高・金利上昇・資源高は、TOPIX・ドル円・銀行株超過・原油の4つを同時に入れた週次の重回帰で測っています。単純に「円高の月の成績」を見ると、円高月は株安の月と重なりやすいため、ディフェンシブ株がどれも強く見えてしまうからです。

タイプ: ◎/○ が3局面以上なら **全天候型**、それ以外は最も強い局面の名前で分類しています。

## 業種ごとの性格

| 業種 | 景気に強い理由・弱点 |
|---|---|
| 通信 | 通信料は景気後退でも解約されにくい。配当・自社株買いが厚い |
| 電力 | 規制料金で需要が安定。燃料費の転嫁は遅れるため資源高には弱いことも |
| ガス | 規制業種で需要が安定。円高・燃料安で利益が出やすい |
| 鉄道 | 定期券・不動産収入で安定。ただし外出制限(コロナ)には弱い |
| 食品 | 生活必需品。値上げで原材料高を転嫁できる企業が多い |
| 飲料・たばこ | 嗜好品だが需要は景気に鈍感。値上げ耐性が高い |
| 医薬品卸 | 薬価に連動する安定収益。景気感応度が極めて低い |
| 日用品 | 洗剤・紙おむつなど生活必需品。景気後退でも数量が落ちにくい |
| 小売(生活必需) | スーパー・ディスカウント店。景気後退で節約需要を取り込む |
| ドラッグストア | 医薬品・日用品の内需。景気後退でも客数が落ちにくい |
| 外食 | 低価格業態は節約志向の受け皿 |
| 警備・サービス | 長期契約の継続収入 |
| ITサービス | 官公庁・大企業向けの保守・継続課金で安定 |
| エンタメ | IP・不動産収入で安定 |

## 注意

- スコアは候補内の相対評価です。過去の値動きから計算しており、将来の下落耐性を保証しません。
- 配当は含めていません（株価は分割調整のみ）。高配当銘柄は実際のトータルリターンがこれより良くなります。
- 「金利上昇」は日本国債利回りが取得できないため、銀行株の対TOPIX超過リターンを代理指標にしています。
- 上方キャプチャが低い銘柄は、上昇相場で TOPIX に置いていかれやすい点に注意（守りが固い裏返し）。
- 個別要因（不祥事・TOB・薬の特許切れなど）による値動きも統計に含まれます。
