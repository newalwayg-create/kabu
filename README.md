# kabu — 日経平均・日経先物・時間外・半導体株・SOX・ダウの相関分析

Yahoo Finance から日足データを収集し、**日米の時差を考慮したうえで**相関関係を分析するツールです。

## 対象データ

| 区分 | 銘柄 (Yahoo ティッカー) |
|---|---|
| 日経平均 | 日経平均株価 `^N225` |
| 日経先物 / 時間外 | CME 日経225先物（円建て）`NIY=F` — 東京市場が閉まっている夜間も取引されるため「時間外」の指標に使用 |
| 日本の半導体株 | 東京エレクトロン `8035.T`, アドバンテスト `6857.T`, レーザーテック `6920.T`, SCREEN `7735.T`, ディスコ `6146.T`, ルネサス `6723.T` |
| 米国半導体 | SOX指数 `^SOX`, NVIDIA `NVDA`, AMD `AMD`, Broadcom `AVGO`, TSMC `TSM`, Micron `MU` |
| ダウ平均 | `^DJI` |
| 参考 | ドル円 `JPY=X` |

銘柄の追加・削除は `kabu_corr/config.py` の `INSTRUMENTS` を編集するだけです。

## 使い方

```bash
pip install -r requirements.txt

python -m kabu_corr run --start 2019-01-01   # データ収集 + 分析
python -m kabu_corr collect --start 2019-01-01  # 収集だけ (data/prices.csv)
python -m kabu_corr analyze                  # 保存済みデータで分析だけ
python -m kabu_corr demo                     # 合成データで動作確認（ネット不要）
```

結果は `output/` に出力されます（`report.md` と PNG グラフ・CSV）。

## 分析の考え方

### 時差の扱い（最重要）
NY市場は東京の引け後に開き、日本時間の翌朝に閉まります。同じ日付どうしで相関をとると
「東京の後に起きた米国の動き」と比べることになり、関係を取り違えます。
そこで **東京の営業日 T には「T の寄付き前に終わった直近の米国セッション（前夜）」** を対応させています。
米国だけ祝日・日本だけ連休明けといった日も、終値ベースで変化を累積して正しく対応させます。

### 出力される分析
1. **相関行列**（ヒートマップ）— 全銘柄の日次リターン相関
2. **日経平均との相関ランキング**（p値つき）
3. **ラグ相関** — 前夜・前々夜・東京引け後の米国、どれが日経平均と最も連動するか
4. **時間外と寄付きギャップ** — 日経平均を「前日終値→寄付（時間外の反映）」と「寄付→終値（日中）」に分解し、
   前夜の SOX・ダウ・CME先物がどちらを説明するか、方向一致率も算出。
   `CME_OVERNIGHT` は CME 先物が東京の閉場中に織り込んだ変動の推定値です。
5. **重回帰** — `日経平均 ~ 前夜のSOX + ダウ (+ドル円)` の β・t値・R²、日本の半導体株ごとの SOX β
6. **ローリング相関**（既定60営業日）— 関係の強さの時期による変化
7. **年別相関** — 関係の安定性

### 注意
- 相関は因果を意味しません。
- `NIY=F` はつなぎ足（期近ロール）なので、限月交代日には小さな段差が入ります。
- 大阪取引所の日経225先物（夜間取引を含む）は Yahoo Finance では取得できないため、CME 先物で代用しています。
