## 1. 事例の数え方

- 状態は「パターン（7通り＋G0）×75日線の傾き」の16通りです。
- **ある状態に入った初日だけを1件**と数えます。条件を満たし続けている2日目以降は数えません。
- **中断の扱い**：同じ状態から外れて **3営業日以内** に戻った場合は、同じ事例の続きとみなし、新しい事例にしません。4営業日以上外れてから戻った場合は新しい事例です。
  - 理由：終値が移動平均線をまたいで1〜2日だけ行き来するのは、ほぼ同じ局面だからです。毎回を別の事例と数えると、同じ局面が何重にも数えられます。
- **期間開始日の扱い**：期間の開始日にすでに続いていた状態を「初日」と誤認しないよう、初日の判定は2015年からの全データで行い、その後で期間を切り出しています。

許容日数（gap）を変えた場合の事例数（20日リターンを計算できた件数）：

| 中断の許容日数 | 探索 事例数 | 検証 事例数 | 塩野義型 探索 平均 | KDDI型 探索 平均 |
|---|--:|--:|--:|--:|
| 0（1日でも外れたら新事例） | 22,598 | 7,998 | 1.77% | 2.29% |
| **3（採用）** | **13,741** | **4,791** | **1.74%** | **2.15%** |
| 5 | 11,962 | 4,107 | 1.73% | 2.21% |
| 10 | 9,846 | 3,353 | 1.72% | 2.34% |

許容日数を変えると件数は大きく変わりますが、平均はほとんど変わりません。

**探索と検証の境目**：探索期間の最後の約20営業日（2024/12/3以降）に出た事例は、20日後の結果が検証期間に入ってしまいます。結果の情報が漏れないよう、これらは探索から除外しました。

## 2. 外部環境による暴落の除外

エントリー日（シグナル日）の終値時点で分かる、TOPIX（1306）の直近20営業日の騰落率で判定しました。

| 除外条件 | 探索 除外件数 | 探索 平均／上昇 | 検証 除外件数 | 検証 平均／上昇 |
|---|--:|---|--:|---|
| 除外なし | 0 | 1.49% / 55.9% | 0 | 2.04% / 58.2% |
| −5%以下を除外 | 712 | 1.38% / 55.4% | 285 | 1.77% / 57.1% |
| −7.5%以下を除外 | 165 | 1.42% / 55.6% | 147 | 1.84% / 57.5% |
| −10%以下を除外 | 107 | 1.43% / 55.8% | 25 | 2.01% / 58.1% |

（全事例、20日リターン）

- 除外すると、どの閾値でも平均は下がりました。暴落直後に入った事例は、その後の平均がむしろ高かった（反発した）ためです。
- 塩野義型・KDDI型でも同じ傾向です（`tables_v2.md` の G-2）。例：塩野義型の検証平均は、除外なし 2.58% → −5%除外 2.15%。

## 5. エントリー・イグジット

- **エントリー**：シグナル日の引け／翌営業日の寄付
- **イグジット**（15通り）
  - 固定日数：5・10・20日
  - 株価の上にあった線（25・50・75日）への到達：上限40日

**事実**
- 線への到達で売るルールは、勝率が高くなりました（塩野義型 78〜85%、KDDI型の50日線到達で91%）。ただし平均リターンは、固定20日より低いかほぼ同じです。小さな利益を確定する一方、届かなかった事例の損失が残るためです。
- 利確・損切りの組み合わせは、9通りすべてで固定20日の平均を下回りました（両枝・両期間）。
- 引けで入る場合と翌日寄付で入る場合の差は、+0.1pt程度でした（引けがやや高い）。S株を寄付で約定する前提では、寄付の数字が実際に近い値です。

## 7. 「上がりやすい」とは言えない根拠（反証）

1. **良い枝のほとんどは「TOPIXが移動平均線の下」＝相場全体の下落局面**：探索期間で平均+3〜5%の枝が並びますが、対TOPIX超過は+1%前後です。個別株の形ではなく、相場全体の戻りを拾っている割合が大きいと数字は示しています（前回のv1と同じ傾向）。
2. **その局面は、検証期間にほとんど来なかった**：検証期間の事例は21〜70件で、判定できません。将来も来るとは限らない条件です。
3. **検証期間で崩れた枝がある**：探索で上位6本のうち3本は、検証で平均・上昇割合・超過のすべてが全日以下でした。例：P6上向き → TOPIX 25日線の下は、探索+3.39%に対して検証−1.39%。
4. **KDDI型は検証で優位が消えた**：探索では全日比+0.61pt（有意）でしたが、検証では対TOPIX超過が−0.24%と、全日（+0.18%）を下回りました。上昇割合も全日以下です。
5. **塩野義型は探索期間でも全日と差がない**：CIは[−0.35, +0.81]です。検証期間で上回ったのも、CIが[−0.71, +1.58]で偶然の範囲です。
6. **選択による偏り**：枝を選び、さらに30ルールから最良を選んでいるため、探索期間の成績は実力以上に良く見えます。検証期間で落ちるのは、その分の可能性があります。
7. **独立性の問題**：初日だけを数えても、相場全体が崩れた日には多くの銘柄が同時に同じ状態に入ります。件数が示すほど独立していません。そのため信頼区間は月単位で計算しています。
8. **生存者バイアス・コスト・配当**：現在のTOPIX100（再構成リスト）を遡って使っています。全日でも対TOPIX超過がプラス（探索+0.53%）なのはこのためと推測されます。売買コストは含まず、配当も含みません。
9. **期間の短さ**：検証期間は約1年9か月で、ほぼ上昇相場でした（全日の20日平均が+2.13%）。

## 8. 使った条件の定義

| 項目 | 定義 |
|---|---|
| 移動平均 | 終値の単純移動平均 25・50・75日（証券アプリと一致を確認済み） |
| パターン | 終値より上にある線の組み合わせ：P1〜P7。G0は3本すべてが終値以下 |
| 75日線の傾き | 75日線の当日値と20営業日前の比較（上向き／下向き）。同値は除外 |
| 事例 | 状態（パターン×傾き）に入った初日のみ。3営業日以内の中断は継続とみなす |
| 期間 | 探索 2020-06-01〜2024-12-02（20日後の結果が2024年内に収まる事例のみ）、検証 2025-01-01〜2026-10-13 |
| 20日リターン | 20営業日後の終値 ÷ 翌営業日の始値 − 1 |
| 上昇割合 | 20日リターン > 0 の割合 |
| 対TOPIX超過 | 同じ期間（翌日寄付→20日後終値）の1306のリターンを差し引いた値 |
| 乖離率 | 株価の上にある線のうち、最も近い線に対する終値の乖離（G0は25日線からの乖離） |
| 出来高倍率 | 当日の出来高 ÷ 前日までの20日平均 |
| 足の形 | 反転陽線＝終値>始値かつ終値>前日終値。下ヒゲ＝（始値・終値の低いほう−安値）÷値幅。実体の小さい足＝直近3本の実体（\|終値−始値\|÷終値）の最大値が閾値以下 |
| MACD | (12,26,9) のヒストグラムが負で、前日より上昇した日がn日連続 |
| TOPIXの位置 | 1306の終値が自身の25日／75日線の上か |
| 暴落除外 | シグナル日の1306の直近20営業日騰落率（終値÷20日前終値−1）が閾値以下 |
| 分岐の採用 | 探索期間のみで決定。両側100件以上の分け方の中から、決められた要素で平均の差が最大の閾値 |
| 信頼区間 | 月単位のクラスター・ブートストラップ（2,000回、シード固定） |
| イグジット | `exits.py` の冒頭に詳細。日足のみで判定し、同じ日に利確・損切りの両方に届いた場合は損切りを優先 |
