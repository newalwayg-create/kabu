# 移動平均線の下にある銘柄の反発パターン検証（TOPIX100、2016〜2026年）

株価と移動平均線の位置関係をパターン分けし、それぞれの「その後のリターン」を実データで集計しました。
**結論や売買の推奨は出さず、数字の提示にとどめます。**

- 全数値表（自動生成）：[`results/summary_tables.md`](results/summary_tables.md)
- 設定別の詳細：[`results/base_5_25_75/tables.md`](results/base_5_25_75/tables.md)、[`results/app_25_50_75/tables.md`](results/app_25_50_75/tables.md)
- 感度確認：[`results/sensitivity.md`](results/sensitivity.md)
- 期間別の安定性：[`results/stability.md`](results/stability.md)
- 事例チャート：[`index.html`](index.html)（基本設定・アプリ設定の2つのギャラリーへのリンク）

**基準日に関する注意**：分析は2026-10-13 15:23（JST）に取得したデータで行いました。2026-10-13 の値はザラ場中のものです（Yahoo の約20分遅れ）。10/13 の値は直近の分類確認と直近チャートにだけ影響し、リターン集計（20日後まで必要）には入っていません。

## 1. 定義の確認

### 1-1. 証券アプリの移動平均の期間

2銘柄の6本すべてで、アプリの値と一致する期間（単純移動平均）を総当たりで探しました（`app_ma_match.py`）。10/13 の終値をアプリの現在値に置き換えて計算しています。

| 線 | 一致した期間 | 塩野義 計算値 / アプリ | KDDI 計算値 / アプリ | 2銘柄の最大誤差 |
|---|---|---|---|---|
| 短期 | **SMA 25日** | 2,858.84 / 2,858.8 | 2,975.14 / 2,975.1 | 0.0014% |
| 中期 | **SMA 50日** | 2,872.73 / 2,872.7 | 2,941.75 / 2,941.8 | 0.0017% |
| 長期 | **SMA 75日** | 2,861.37 / 2,861.4 | 2,892.65 / 2,892.6 | 0.0016% |

次点の期間（24日・26日など）では、誤差が0.15〜0.3%に広がります。EMA（指数移動平均）でこれより近いものはありませんでした。
→ アプリの設定は **短期25・中期50・長期75日の単純移動平均** と判断しました。依頼の基本設定（5/25/75日）とは短期・中期が異なるため、本検証は**両方の設定で同じ集計**を行っています。

## 3. 日経平均・TOPIXとの比較

### 3-1. 超過リターン（個別株の20日リターン − 同じ期間の指数リターン）

- 全日の対TOPIX超過は **+0.34%**、対日経平均は **+0.10%** です。現在のTOPIX100構成銘柄を過去に遡って使っているため、生存者バイアスの分だけ構造的にプラスになっていると推測されます。
- 塩野義型の超過は、基本設定で+0.58%（全日比+0.24pt、差なし）、アプリ設定で+0.54%（+0.20pt、差なし）です。**絶対リターンの上乗せ（+0.97pt／+0.85pt）のうち、約3/4は同じ期間の指数の上昇で説明できます。**

## 7. 「上がりやすい」とは言えない根拠（反証）

1. **塩野義型の上乗せは、主に指数の動き**：対TOPIXの超過にすると、上乗せは+0.20〜+0.24ptに縮み、有意ではなくなります。日経平均が75日線の上にある局面では、絶対リターンでもほぼ上乗せがありません（+0.05pt／アプリ設定は−0.09pt）。「個別株が移動平均線に戻る力」ではなく、「相場全体の下落局面の後に全体が戻した」ことを拾っている可能性が高い、と数字は示しています。
2. **KDDI型は、全日と区別できない**：絶対で+0.22〜+0.31pt、超過で−0.02〜+0.09ptで、いずれもCIが0をまたぎます。期間の前半と後半で、超過の符号が逆です。
3. **「戻りかけ」の到達率は全日並み**：株価の上にあった線へ20日以内に届いた割合は、全日の平均とほぼ同じです。塩野義型で長期線に届いたのは40%で、むしろ低い水準です。
4. **下値リスクは減っていない**：20日以内の最大下落幅の平均は、どのグループも約−5〜−6%で、下位5%の事例では−13〜−18%です。
5. **よく使われる「底打ちサイン」の多くは効かなかった**：値幅の縮小は一貫して結果を悪化させました。出来高・下ヒゲ・陽線の効果は小さく、閾値で符号が変わります。
6. **多重比較**：16グループ × 3期間 × 2指数 × 2設定 × 多数の条件を検定しています。5%水準でも、偶然に「有意」になるものが一定数出ることが避けられません。一度だけ有意になった結果（例：P4下向きの対TOPIX超過＝基本設定のみ有意、アプリ設定では非有意）は、特に割り引いて見る必要があります。
7. **生存者バイアス**：2026年時点の大型株100社（再構成リスト）を10年遡って使っています。途中で除外・上場廃止になった銘柄（例：豊田自動織機は取得不可）が入っていないため、全体的に結果がプラスに偏ります（全日の対TOPIX超過が+0.34%／20日）。
8. **コストを含まない**：売買手数料・スプレッド・寄付の約定ずれは考慮していません。配当は含まない値上がり益です。差の大きさ（+1pt前後／20日）に対して、無視できない可能性があります。
9. **期間の偏り**：2016〜2026年は日本株が大きく上昇した期間です（全日の20日リターン平均+1.27%）。下落が続く相場で同じ結果になる保証はありません。

## 9. 検証に使った条件の定義

| 項目 | 定義 |
|---|---|
| 移動平均 | 終値の単純移動平均。基本設定：短期5・中期25・長期75日。アプリ設定：25・50・75日。感度確認：5/20/60、10/25/75 |
| 起点 | 当日の終値が、3本の移動平均のうち少なくとも1本を下回る（線 > 終値） |
| 分岐1（P1〜P7） | 終値より上にある線の組み合わせ。G0 は3本すべてが終値以下 |
| 分岐2（長期線の傾き） | 長期線の当日値と、k営業日前の値の比較。基本 k=20、感度確認 k=10/40。同値は除外 |
| エントリー | シグナル日の翌営業日の始値 |
| H日リターン | H営業日後の終値 ÷ エントリー価格 − 1（H=5/10/20） |
| 最大下落幅 | 保有期間中の安値の最小値 ÷ エントリー価格 − 1 |
| 線への到達 | 保有期間中の高値の最大値が、シグナル日の線の値以上（その線が株価の上にあった事例のみで計算） |
| 超過リターン | 個別株のH日リターン − 同じ期間（翌日始値→H日後終値）の指数リターン |
| 指数の状態 | シグナル日の指数の前日比、指数の5/25/75日線との位置 |
| 出来高倍率 | 当日の出来高 ÷ 前日までの20日平均 |
| 下ヒゲ | （始値と終値の低いほう − 安値）÷（高値 − 安値） |
| 反転陽線 | 終値 > 始値 かつ 終値 > 前日終値 |
| 値幅縮小 | 直近3本の実体（\|終値−始値\|÷終値）の最大値が閾値以下 |
| MACDヒストグラム縮小 | MACD(12,26,9) のヒストグラムが負で、前日より上昇した日がn日連続 |
| 信頼区間 | 月単位のクラスター・ブートストラップ（2,000回、乱数シード固定）の2.5〜97.5%点 |
| 信頼性ラベル | 件数300未満または24か月未満＝低、1,500未満＝中、それ以上＝高（件数の目安にすぎない） |
