# ② 株価状況と「上げていない銘柄」の抽出

- 起点：2026-10-01 の始値
- 終点：**2026-10-09（金）の終値**。10/12（月）はスポーツの日で休場。基準日の10/13は取得時点（14:04 JST）でまだ取引中だったため、確定している直近の終値を使った（利用者の了承済み）。10/13の取引中の値は参考として別に示す。
- 期間：6営業日（10/1, 2, 5, 6, 7, 8, 9 のうち取引のある日）
- データ：Yahoo Finance chart API の日足（`fetch_prices.py`、出力は `data/step2_returns.csv` と `data/prices_daily.csv`。取得 2026-10-13 14:04 JST）
- 分類：騰落率 = 10/9終値 ÷ 10/1始値 − 1。+5%以上を「上げた」、+5%未満を「上げていない」とした。
- 本資料は判断材料の整理です。売買の推奨ではありません。

## 5. 観察（事実と推測を分けて記載）

**事実**
1. Aランクは15銘柄すべてが+5%以上で、中央値は+28.1%。日経平均（+2.87%）を全銘柄が上回った。最も低いHENNGE（+6.11%）でも+3.2pt上。
2. 上昇率の上位は、時価総額が小さく、それまで売買代金が極端に少なかった銘柄。
   - ブロードバンドセキュリティ：直前同日数の売買代金0.6億円 → 134億円
   - セキュアヴェイル：0.5億円 → 228億円
   - アズジェント：0.3億円 → 189億円
3. 急騰した銘柄の多くは、期間中の高値から大きく下げて10/9を終えている（アズジェント −21.5%、エルテス −24.8%、ZenmuTech −18.6%、テリロジー −16.6%）。
4. 起点の10/1より前から上げていた銘柄が多い。例：ZenmuTech は 9/30〜10/1 に連続ストップ高（[株探](https://kabutan.jp/stock/news?code=338A&b=n202610060344)）、FFRI は 10/1 に +11.95%（[EBC](https://www.ebc.com/jp/forex/314322.html)）。それでも10/1の寄り付きのギャップは大半が±2%以内で、ZenmuTechだけが+4.2%。
5. 10/13の取引中（14:04時点）は、日経平均が10/9比で約−1,700円（−2.5%前後）と大きく下げた（AI・半導体の急落）。一方で、A銘柄の10/1起点騰落率の中央値は +38.3%（10/9終値基準の+28.1%から上昇）で、テーマへの買いは続いていた。

**推測**
- Cランクの「上げていない」10銘柄は、サイバー売上の比率が低い（①で推定数%以下）。値動きはサイバー以外の要因（通信・電機・SIの業績や金利など）で決まっている可能性が高い。今回のテーマ物色の対象になっていなかったと読むのが自然。
- 一方で、日立 +20.6%、NTT +19.2%、電通総研 +33.7%、デジタルハーツ +42.9% は、7〜9月にすでに大きく上げている。「期間内で上げていない」ことは「割安で放置されている」ことを意味しない。
- 7〜9月も上げていないのは、三菱電機（−12.8%）、セコム（−3.4%）、イー・ガーディアン（+0.3%）、ソースネクスト（+2.0%）の4銘柄。
- Bランクで唯一の「上げていない」ピー・ビーシステムズは、売買代金が2.7億円と小さく、テーマ資金がほとんど入っていない。

## 6. 反証（この見立てが外れる根拠・データ）

1. **終点の選び方で分類が変わる**：10/13の取引中の値で計算すると、トビラ（+5.13% → +1.00%）とIIJ（+7.26% → +3.56%）が「上げていない」に移り、ソースネクスト（+2.88% → +5.77%）は「上げた」に移る。日立とセコムも+4.95〜4.96%で境界上にある。6営業日という短い期間では、分類の安定性は低い。
2. **5%という基準は絶対値**：日経平均自体が+2.87%上げているので、5%は指数比で+2.1pt程度の差にすぎない。TOPIX（+0.2%）を基準にすれば、Cランクの「上げていない」銘柄の多くも市場並みかそれ以上。どちらの指数を基準にするかで「相対的に弱い」かどうかの評価が変わる。
3. **出遅れ（キャッチアップ）は起きないかもしれない**：Cランクは売買代金が直前期間より8%減っており（0.92倍）、テーマ資金が大型株に向かった形跡はない。大型株はサイバー比率が低く、テーマで物色される根拠が弱い。過去の経緯から「大型株に資金が移る」と仮定するのは根拠不足。
4. **上げた銘柄の上昇は持続しないかもしれない**：上位は流動性の低い小型株に資金が集中した結果で、各社とも上方修正などの業績材料はない（①の市場環境で示した報道）。期間中の高値から20%前後下げている銘柄もあり、テーマの持続性についての反証になりうる（③で検証する）。
5. **データの制約**：TOPIXの指数値は第三者サイトの値で、始値は列の並びを解釈して読んだもの。Yahooの日足は分割調整済みだが、配当落ちは調整していない（9月末の配当落ちは起点より前なので影響は小さい）。
