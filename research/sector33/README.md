# 東証33業種での資金移動の検証（2026-10-08）

`research/sector`（独自の9業種）の検証を、Yahoo!ファイナンスの業種区分のもとになっている東証33業種でやり直したもの。
各業種は時価総額上位の代表銘柄（計161銘柄、`universe.py`）を時価総額で加重。結果のページ: https://claude.ai/artifact/3WhXy3gchoToa3pPzrznpx

| 仮説 | 33業種での判定 | 9業種での判定 |
|---|---|---|
| 金利上昇で半導体・AIが売られ、ディフェンシブへ | 否定（金利上昇で最も下げるのは不動産業） | 否定 |
| 金利上昇で銀行・保険へ | 支持（銀行業 +1.65%、t 5.2） | 支持 |
| 中東リスクで海運へ | 支持。ただし鉱業（t 8.1）・石油石炭（t 5.0）の方が強い | 支持 |
| 半導体から使う側・守る側へ | 33業種では確認できない（電気機器に薄められる） | 一部支持 |
| 半導体は調整後、決算で戻る | 業種単位では弱い支持（電気機器は今は高値から −2.9%） | 根拠不十分 |
| サイバーは独立したテーマとして続く | 33業種では検証できない（区分がない） | 独立は支持、継続は不支持 |

```bash
cd research/sector33
python fetch.py              # データ取得（数分）
python analyze.py            # 検証
python export.py out.html    # ページを作る
```
