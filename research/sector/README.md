# 業種間の資金移動の検証（2026-10-08）

9業種・53銘柄の株価と売買代金、金利（米10年・国内債券ETFから推定した国内金利）、原油（ブレント）、SOX を使い、
日本株の資金移動に関する6つの仮説を検証しました。結果のページ: https://claude.ai/artifact/ESUPSDRGbP2D27dz4RDrxh

| 仮説 | 判定 | 主な根拠 |
|---|---|---|
| 金利上昇で半導体・AIが売られ、ディフェンシブへ | 否定 | 半導体は金利と無関係（t −1.0/+0.8）。ディフェンシブは金利上昇週にむしろ弱く、上がるのは半導体安の週（SOX との関係 t −5.6〜−10.7）。金利に弱いのは AI活用・ITサービス（t −3.0） |
| 金利上昇で銀行・保険へ | 支持 | 国内金利が大きく上がった週に銀行 +1.76%（t 5.6）、保険 +0.93%（t 3.0） |
| 中東リスクで海運へ | 支持（原油で代用） | 原油が大きく上がった週に海運 +2.05%（t 3.7）。直近3か月はブレント +46%、海運 +31% |
| 半導体から使う側・守る側へ | 一部支持 | 直近3か月は 半導体 −9.6%、AI活用 +21.2%、サイバー +51.6%、売買代金の半導体比率 84%→71%。ただし長期では無関係、直近1か月は半導体 +16% |
| 半導体は一時的な調整で決算で戻る | 根拠不十分 | 下落10〜20%局面の3か月後は +6.8%（普段 +9.0%）。出遅れ後の決算は反応 +1.6% だが20日後 −0.6% |
| サイバーは独立したテーマとして続く | 独立は支持、継続は不支持 | 市場と要因で説明できるのは28%。過去12か月好調後の翌月は −0.6% |
