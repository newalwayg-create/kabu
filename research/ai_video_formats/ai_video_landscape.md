# 生成AIショート動画のフォーマット調査（判断材料の整理）

作成日：2026-10-22
目的：生成AI・コード（Claude Code＋Remotion等）で作るショート動画について、フォーマットごとの需要・供給・タイミング・参入障壁・規約リスク・受け止めの材料を集める。
**推薦・結論・順位づけはしない。** 判断は依頼者が行う。

---

## 0. 作業上の解釈・制約（必読）

### アクセスできたもの・できなかったもの
| 対象 | 状況 | 対応 |
|---|---|---|
| Google Trends | **アクセス不可**（環境のネットワーク制限） | 検索ボリュームの推移は「データなし」とした。報道に書かれたトレンドの記述だけを拾った |
| TikTok Creative Center | **アクセス不可**（同上） | ハッシュタグの投稿数・再生数の推移は「データなし」 |
| YouTube 検索結果ページ | 接続はできた（HTTP 200） | **使っていない。** YouTube 利用規約は、公式APIなど許可された方法以外の自動アクセスを禁じているため |
| 一般のWebページ | 直接取得は不可（前回と同じ） | Web検索の結果（ページの抜粋・要約）で情報を集めた |

### 自分で追加調査するときに必要なもの（実行していない）
- **YouTube Data API v3 のAPIキー**（Google Cloud で発行）：検索結果の本数、チャンネル登録者数、再生数、投稿日を規約の範囲内で取得できる。フォロワー数に対する再生数の比率や、新規参入数の推移を測るのに必要。
- **Google Trends**：ブラウザで手作業で確認する（公式APIは限定公開）。
- **TikTok Creative Center**：ブラウザで確認（一部はログイン不要）。**TikTok Research API** は研究者向けの申請・承認が必要。
- **Instagram**：公開の検索・統計ツールは確認できなかった。Graph API は自分のアカウントのデータしか取れない。

### 解釈したこと
- 「フォーマット」は、**見た目の型と構成の型**（例：ガラスフルーツを切るASMR、ボール脱出シミュレーション）として扱った。「ジャンル」はその上位分類（ASMR、解説など）。
- (A)＝コードで描画するもの（Remotion、Python、Manim など）。(B)＝動画生成AI（Veo、Kling、Sora など）。両方を使うものは「A+B」と書いた。
- 「段階」（上昇・ピーク・下降）は、**日付つきの報道で初出時期とピークの記述があるものだけ**書いた。それ以外は「不明」。
- 保存・シェアの数や、フォロワー数に対する再生数の比率は、どのフォーマットでも信頼できる資料が見つからなかった。表の欄は原則「データなし」。

### 出典ラベル
- 【一次データ】プラットフォームの公式発表・ヘルプ、論文、公的統計（ただし今回はすべて検索結果の抜粋で確認したもので、ページを直接読んではいない）
- 【独立した二次情報】報道機関、ファクトチェック機関、百科事典（Wikipedia 等）、利害関係のない第三者の分析
- 【宣伝目的の可能性あり】AIツール販売会社、副業ノウハウ販売（Gumroad 等）、マーケ会社・MCN、SEOブログ

## 1. フォーマット共通の前提（収益・規約・受け止め）

### 1-1. 収益の仕組み（CPM・RPM・ショートと長尺は混ぜない）
| 項目 | 内容 | ラベル |
|---|---|---|
| YouTubeショートの収益化の仕組み | ショートフィードの広告収入を毎月まとめ、音楽ライセンス費用とクリエイタープールに分ける。プールは再生シェアで配分され、クリエイターの取り分は45%。プールが広告収入全体の何%かは非公開 | 【一次データ】（YouTube の発表を引用した報道で確認） |
| YouTubeショートのRPM（国別） | 米国 約$0.328、日本 約$0.144（9位）、インド 約$0.008（1,000再生あたり） | 【宣伝目的の可能性あり】AIR Media-Tech（クリエイター支援・MCN） |
| ショートと長尺のRPMの比 | ショートのRPMは、ほぼ全ジャンルで長尺の3〜14% | 【宣伝目的の可能性あり】AIR Media-Tech（274チャンネルの集計とされる） |
| 日本のショートの1再生単価（目安） | 0.003〜0.01円／再生（1,000再生で3〜10円）が最も多く書かれる目安 | 【宣伝目的の可能性あり】国内の副業・マーケ系記事。YouTube 公式は単価を公表していないと明記する記事もある |
| 広告主側のCPM（日本） | 300〜700円、400〜600円など | 【宣伝目的の可能性あり】広告代理店の記事。**クリエイターの受取額とは別** |
| TikTok Creator Rewards | **1分を超える動画だけが対象。** フォロワー1万人以上、直近30日の再生10万回以上、18歳以上。対象国に日本を含む | 【一次データ】TikTok Creator Academy（検索抜粋） |
| Instagram | 一般的な広告収益の分配制度は確認できない。ボーナスは招待制・地域限定で、現状は不明（前回のC2を参照） | 【独立した二次情報】／一部は【宣伝目的の可能性あり】 |
| YouTubeショートの再生数 | 1日2,000億回超（2025年6月 CEO 発言、2026年8月にも同じ数字）。2025年3月31日から、スワイプして流れた分も1再生に数えるよう定義を変えたので、以前の数字（700億回）とは比べられない | 【一次データ】（公式発言を引用した報道） |

**材料として読み取れること（評価ではなく構造）**
- 60秒未満のショートは、TikTok の Creator Rewards の対象外。
- 広告収益の分配が確認できるのは YouTube ショートだけ。
- ノンバーバルで全世界向けにすると、RPM の低い国（インドなど）の再生比率が上がる可能性がある。ただし国別の再生構成を実測したデータはない。

### 1-2. 規約（全フォーマットに共通）
- **YouTube**
  - 2025年7月15日に「repetitious content」を「inauthentic content」に改称した。テンプレートで量産したような、作り手の独自の視点がないAIコンテンツは収益化の対象外。AIの利用そのものは問題にならない。【一次データ】
  - 2026年7月の更新では、収益化できないものとして「汎用的・反復的なもの」「unsatisfying or off-putting（満足感がない、または不快なもの）」「偽のAI専門家」の3類型が示された。見出しのみ確認で、定義の本文は未確認。【独立した二次情報】Tubefilter
- **YouTube のAI開示義務**：本物と見間違える可能性がある合成コンテンツには開示が必要。**明らかに非現実的なもの・アニメーションは対象外。** 開示しない場合、削除やYPP（パートナープログラム）停止の可能性がある。【一次データ】（2024年3月から適用。報道で確認）
- **TikTok**：本物に見えるAIコンテンツはラベル付けが必須。C2PAメタデータで自動的に検出する。視聴者はAIコンテンツの表示量を減らせる設定がある。【一次データ】TikTok Newsroom
  - 「AIと判定されると配信が減る」という説は【宣伝目的の可能性あり】の資料にしかない。
- **Instagram／Meta**：大半が転載のアカウントはおすすめに出さない（2026年4月30日にリール以外にも拡大）。任意の「AI creator」ラベルのテスト（2026年5月）。【一次データ】／【独立した二次情報】
- **YouTube の取り締まり事例**
  - 2025年12月：フェイク映画予告の2チャンネル（Screen Culture、KH Studio）を削除。合計再生約10億回。【独立した二次情報】
  - 2026年1月：16チャンネル（累計47億再生）を削除したと報じられている。【独立した二次情報】Tubefilter／一部は【宣伝目的の可能性あり】

### 1-3. 視聴者の受け止め（全体）
- **AI開示の影響**
  - Journal of Consumer Research「Made With AI」：TikTokのデータと事前登録された8つの実験。AIGC の開示があると、品質が同じでもエンゲージメントが下がる（業界誌の要約ではいいね数で7〜8%減）。原因は作り手への親近感（パラソーシャルなつながり）の低下とされる。【一次データ】
  - MIT Berinsky ほか：「AI-Generated」ラベルでは、共有・いいねの意向に有意な影響がない。【一次データ】
  - 研究によって結果が分かれている。
- **AIスロップの量**
  - Kapwing の新規アカウント試行で、YouTubeショート 21%、TikTok 59%。【宣伝目的の可能性あり】（ツール会社。いずれもアカウント1つでの試行）
  - NYT の検証では、子ども向け動画の推薦の40%超にAI生成の兆候があった。【独立した二次情報】
- **プラットフォームの姿勢**：YouTube CEO は低品質AIコンテンツへの対策を2026年の優先課題とし、同時にAI制作ツールを拡大すると表明。【一次データ】（報道経由）

## 2. フォーマット別の整理

表記：「データなし」＝信頼できる資料が見つからなかった。

### F1. AI ASMR（ガラスフルーツなどを切る）【B】
- **需要**
  - 1チャンネルの個別動画が450万／2,600万／6,740万再生（2025年）。【独立した二次情報】Fast Company
  - 検索ボリュームの推移はデータなし（Google Trends 不可）。「AI ASMR」のトレンドデータは報道にもない。
- **供給**：TikTok で「数千本」（Dexerto、2025年）。【独立した二次情報】現在の本数はデータなし。
- **タイミング**：2025年5月の Veo 3 公開後に広まった。【独立した二次情報】「成熟しつつある」という見方は【宣伝目的の可能性あり】の資料のみ。段階は不明。
- **参入障壁**：プロンプトやチュートリアルが広く出回っている。動画生成AIの費用がかかる（Veo 3 は Google AI Ultra で月$250と報じられている）。言語の壁はない。
- **規約リスク**：中〜高。似た動画の連続投稿は「テンプレート量産」に当たりうる。本物に見えるので開示が必要になる可能性がある。
- **受け止め**：好みが分かれる（「戸惑う」TechRadar、「渋々評価」Fast Company）。【独立した二次情報】
- **対象**：ノンバーバル、全世界。

### F3. 物理シミュレーション（ボール脱出・バウンドと音）【A】

- **供給**

  - コードで1日4本を自動生成するシリーズ（Loop Physics）がGitHubでリリースを公開している（2026年10月）。【宣伝目的の可能性あり】（当事者の公開情報）

- **タイミング**：2023年11月に初めて流行。現在の段階は不明（約3年経過）。
- **参入障壁**：コードが必要（Claude Code で代替できる余地あり）。生成AIの費用はかからない。言語の壁はない。
- **規約リスク**：高め。同じ型で毎日量産する運用は、「テンプレートでほとんど違いがない」というYouTubeの例示に近い。
- **受け止め**：AI生成ではなくプログラム描画なので「AIスロップ」の文脈では語られにくい。ただし「brainrot」とは呼ばれる。【独立した二次情報】
- **対象**：ノンバーバル、全世界。

### F4. データ可視化（バーチャートレース・数値比較）【A】
- **需要**：Data Is Beautiful チャンネルが、バーチャートレースを始めてから約87万人の登録者を獲得した（長尺、2019年ごろ）。【独立した二次情報】OMR

- **タイミング**：長尺では2019年ごろがピークで、専門家の反発もあった。【独立した二次情報】Built In。ショートでの段階は不明。

- **受け止め**：「データ可視化として不適切」という専門家の批判がある。AIスロップとは見なされにくい。

## 3. 「需要のシグナルはあるが、供給が少ない可能性がある」領域の候補

**順位はつけない。** 各候補は「可能性」で、供給の少なさを実測したデータは**どの候補にもない**（YouTube Data API などでの実測が必要）。

### 候補X1：コードで作る（A）ノンバーバルの物理・工学シミュレーション × 「ボール脱出」以外の題材
（例：流体・振り子・歯車・構造の破壊などの実際の物理法則。気持ちいい系の文法でコード描画する）
- **支える根拠**
  - 物理シミュレーションのショートは、2023年に6,700万再生級の需要実績がある。【独立した二次情報】
  - コード描画は「AIスロップ」の主な対象（動画生成AIによるリアル映像）とは別扱いされやすく、YouTube のAI開示義務の対象外（アニメーション）。【一次データ】
  - 動画生成AIの費用がかからず、ノンバーバルで全世界向けにできる。
- **反対方向の根拠**
  - 同じ系統（Loop Physics など）がすでに1日4本の自動生成を公開しており、**コードによる量産は既存の供給者もやっている。**【宣伝目的の可能性あり】
  - 毎日の量産は、YouTube の「テンプレートでほとんど違いがない」という例示に近い。【一次データ】
  - ボール脱出系は2023年から約3年経っていて、ジャンル全体として新しくない。
  - ノンバーバルにすると RPM の低い地域の再生比率が上がる可能性がある（実測データなし）。

### 候補X2：素材変形・ASMR系（B）× まだあまり使われていない題材（例：日本の伝統素材・工芸〔漆、和紙、金箔、和菓子〕）
- **支える根拠**
  - 「ガラス切りは成熟しつつあるが、新しい形式には余地がある」という見方がある。【宣伝目的の可能性あり】（ツール販売サイトなので割り引いて扱う）
  - 日本の職人技のASMR風動画（木版画など）は海外で見られている事例がある。【独立した二次情報】Open Culture（ただし数字なし）
  - ノンバーバルで全世界向けにできる。
- **反対方向の根拠**
  - ASMR全体・変形系は、テンプレートアプリで誰でも作れ、題材を差し替えるだけでは参入障壁にならない。
  - AIの開示でエンゲージメントが下がるという研究がある（JCR）。【一次データ】
  - 本物の工芸に見えると開示が必要で、実在の工芸を誤って描くと批判される可能性がある。
  - 題材別の供給・需要データはない（データなし）。

### 候補X3：A（コードの図解）× B（リアルな物理映像）を組み合わせた「なぜそうなるか」の解説（例：ガラスが割れる仕組みを、リアル映像＋応力の図解で見せる）
- **支える根拠**
  - 視聴理由として「学べる」が上位（前回のA2）。
  - 解説・教育価値は、YouTube の規約上、独自性を示しやすい方向（ノウハウ記事・規約の例示の両方）。【一次データ】／【宣伝目的の可能性あり】
  - 気持ちいい系の需要（F1、F2）と解説の需要をつなぐ形。
- **反対方向の根拠**
  - **この組み合わせの需要を示すデータは見つからなかった**（データなし）。
  - 制作の難しさ（科学的な正確さ、AとBの合成）が上がる。
  - 説明を入れると言語依存になり、ノンバーバルの利点が弱まる。
  - ショートの尺（とくにTikTokの収益化には1分超が必要）と、解説の情報量が合わない可能性がある。

### 候補X4：データ可視化（A）× 日本ローカルの題材（日本語で日本向け）

  - バーチャートレースは長尺で大規模な需要の実績がある。【独立した二次情報】

  - 日本語でもAI歴史ドラマのチャンネルが複数ある（長尺中心）。
  - ショートでの日本史のAI再現は事例が少なく見える（本数は未計測で、事例ベースの印象）。

  - 「歴史POV」は世界的にはすでに教材販売の対象になるほど一般化している。【宣伝目的の可能性あり】
  - 供給・需要とも計測データはない。

### 候補X6：動物・果物キャラのマイクロドラマ（B）× ノンバーバル化（せりふなし、表情と音だけで進む連続もの）
